# Запуск и редактирование PODSH_UL

Рабочая папка: `C:\Users\Кирилл\Documents\Codex\2026-09-29\bearingshop\MySite`.

## Как запустить

1. Откройте рабочую папку.
2. Дважды щёлкните `start.cmd`.
3. Не закрывайте появившееся окно, пока работаете с сайтом.
4. Откройте http://localhost:3000/catalog.

Docker Desktop не нужен. Для остановки нажмите `Ctrl+C` в окне сайта.

При первой установке на другом компьютере установите Node.js 22 или новее и один раз выполните `npm.cmd install` в папке проекта.

## Как изменить товары

Рабочий каталог находится в `data\catalog.xlsx`. На первом листе:

- колонка A — обозначение подшипника;
- колонка B — количество в штуках;
- колонка C — цена за одну штуку в рублях.

Сохраните Excel и перезапустите `start.cmd`. Сайт сам прочитает таблицу; импорт в базу больше не требуется. Пустые строки и строка заголовка пропускаются. Для `2-36114Л(3гпз)` пустой остаток считается равным 0.

Обновление Excel на компьютере не меняет интернет-версию автоматически. Файл нужно зафиксировать в Git, отправить на GitHub и развернуть на Render.

## Как устроен проект

Браузер обращается к приложению Next.js. Оно читает товары из `data/catalog.xlsx`, выполняет поиск и строит страницы карточек. В Render работает одна web-служба. Отдельные API и PostgreSQL для каталога больше не используются.

| Что редактировать | Файл |
| --- | --- |
| Товары, цены и остатки | `data/catalog.xlsx` |
| Главную страницу | `apps/web/app/page.tsx` |
| Каталог, поиск и сортировку | `apps/web/app/catalog/page.tsx`, `apps/web/lib/catalog.ts` |
| Карточку товара | `apps/web/app/product/[id]/page.tsx` |
| Цвета и внешний вид | `apps/web/app/globals.css` |
| Шапку, подвал и контакты | `apps/web/app/layout.tsx` |
| Настройки публикации Render | `render.yaml` |

Поиск не учитывает регистр и принимает часть обозначения или несколько фрагментов. Каталог показывает по 50 позиций на странице. Сортировка работает по обозначению, цене и остатку.

## Проверка перед публикацией

```powershell
npm.cmd run build -w @bearing/web
```

Если сборка завершилась без ошибок, код готов к публикации. Старые папки `apps/api`, Prisma и `docker-compose.yml` сохранены как архив прежней архитектуры и для запуска витрины не нужны.
