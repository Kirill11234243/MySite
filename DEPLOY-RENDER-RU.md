# Публикация PODSH_UL на Render

Интернет-версия состоит из одной бесплатной web-службы `podsh-ul`. Она запускает Next.js и читает `data/catalog.xlsx` прямо из репозитория. Отдельный API и PostgreSQL не требуются.

## Обновление сайта

1. Измените код или `data/catalog.xlsx`.
2. Проверьте проект командой `npm.cmd run build -w @bearing/web`.
3. Зафиксируйте изменения и отправьте ветку `bearing-shop-mvp` на GitHub.
4. В Render откройте `podsh-ul` и запустите **Manual Deploy → Deploy latest commit**, если автоматическое развёртывание отключено.
5. После статуса **Live** проверьте главную, `/catalog`, поиск и карточку товара.

На бесплатном тарифе служба засыпает без посетителей. Первое открытие может занять около минуты, последующие страницы работают быстрее. Каталог не зависит от пробуждения второй службы.

## Первый запуск через Blueprint

1. Войдите на https://dashboard.render.com через GitHub.
2. Выберите **New → Blueprint**.
3. Подключите `Kirill11234243/MySite`, ветку `bearing-shop-mvp`.
4. Render прочитает `render.yaml` и предложит одну web-службу `podsh-ul`.
5. Нажмите **Apply** и дождитесь статуса **Live**.

## Собственный домен

Без покупки домена сайт работает по адресу https://podsh-ul.onrender.com. Собственный домен подключается в Render через **Settings → Custom Domains**; затем у регистратора нужно указать DNS-записи, показанные Render.

## Что проверить

- `https://podsh-ul.onrender.com/` открывается по HTTPS;
- `/catalog` показывает 2 234 позиции;
- поиск находит известное обозначение;
- карточка показывает цену и остаток;
- `/sitemap.xml` содержит страницы товаров;
- ссылки на телефон и почту работают.
