# Статическая версия без задержки пробуждения

Команда `npm.cmd run build:static -w @bearing/web` создаёт готовый сайт в `apps/web/out`. Все 2 234 карточки, главная, каталог, robots.txt и sitemap.xml создаются заранее. Поиск, сортировка и переходы страниц выполняются в браузере.

Для локального редактирования используйте `start.cmd`, как раньше. После изменения Excel пересоберите статический сайт и опубликуйте его.

## Публикация на Render Static Site

В Render выберите New → Static Site и подключите репозиторий Kirill11234243/MySite.

- Branch: bearing-shop-mvp
- Build Command: npm ci && npm run build:static -w @bearing/web
- Publish Directory: apps/web/out
- Environment: NODE_VERSION=22
- SITE_URL: точный публичный адрес статического сайта или ваш домен (с https://, без завершающего /).

В `render-static.yaml` сохранён пример отдельного бесплатного статического сервиса. Существующая веб-служба остаётся описана в `render.yaml`, чтобы перенос можно было проверить до переключения.

Старый адрес .onrender.com принадлежит существующей веб-службе. Новому статическому сервису Render выдаст отдельный адрес. После покупки своего домена подключите его к статическому сервису и задайте этот домен в SITE_URL. Не удаляйте старый сервис до проверки нового и планирования переноса адресов.

После публикации проверьте поиск, сортировку, прямой переход в карточку и sitemap.xml. Добавьте основной адрес в Яндекс Вебмастер и Google Search Console, затем отправьте sitemap.xml. При смене основного адреса нужен корректный перенос, чтобы не создавать конкурирующие копии в поиске.
